BASIC OF HTML

1 . HTML stands for HyperText Markup Language.
2 . <p> tag is used for paragraphs.
3 . <em> tag is used to emphasize text.
4 . <strong> tag makes text bold.
5 . <a> tag creates hyperlinks.
6 . <img> tag displays images.
7 . <div> is a block container.
8 . <span> is an inline container.
9 . <form> collects user input.
10. <input> is used inside forms.
11. <button> creates a button.
12. <ul> creates an unordered list.
13. <ol> creates an ordered list.
14. <li> defines list items.
15. <table> creates a table.

  
BASIC OF CSS

1 . CSS stands for Cascading Style Sheets.
2 . CSS is used to style HTML elements.
3 . <style> tag is used for internal CSS.
4 . <link> tag connects external CSS file.
5 . color property changes text color.
6 . background-color sets background color.
7 . font-size controls text size.
8 . margin adds outer spacing.
9 . padding adds inner spacing.
10. border adds border around elements.
11. display property controls layout.
12. flexbox is used for flexible layout.
13. grid is used for advanced layouts.
14. hover adds effects on mouse over.
15. CSS makes websites attractive.

  
BASIC OF JAVA SCRIPT

1 . JavaScript makes websites interactive.
2 . <script> tag is used to add JavaScript.
3 . Variables store data values.
4 . let, var, and const declare variables.
5 . Functions perform specific tasks.
6 . Events respond to user actions.
7 . onclick handles click events.
8 . alert() shows popup messages.
9 . console.log() prints in console.
10. document.getElementById() selects elements.
11. JS can change HTML content.
12. JS can change CSS styles.
13. Arrays store multiple values.
14. Loops repeat code.
15. JavaScript makes websites dynamic.
